# .NET Developer --- Technology & Skills Master Matrix

## 1. Purpose

This document consolidates the technologies appearing across the
supplied resume variants, removes duplication, classifies them by
technical area, and then adds a **recommended industry skill set for a
10-year .NET developer**.

### How to read this document

-   **Resume** = explicitly present in at least one supplied resume.
-   **Recommended** = not necessarily stated in the resumes, but
    important for a senior/lead-level .NET engineer in the current
    enterprise market.
-   **Priority**
    -   **Core** --- should be strong for a 10-year .NET developer.
    -   **Strong** --- highly valuable and commonly expected.
    -   **Useful** --- valuable depending on role/company.
    -   **Legacy/Specialized** --- worth understanding when maintaining
        enterprise systems, but not a primary modern-stack focus.

The resume set consistently positions the candidate as a **10-year Full
Stack .NET developer** with experience spanning legacy enterprise
applications, modern distributed systems, Azure, frontend frameworks,
DevOps, and AI-assisted development. The resumes explicitly mention C#,
ASP.NET, .NET Core, Web Forms, MVC, Web API, VB.NET, microservices,
Orleans, GraphQL, RabbitMQ/MassTransit, Angular/Vue/React, Azure, AWS,
SQL databases, Docker, Kubernetes, CI/CD, testing, identity/security,
and AI tooling.
